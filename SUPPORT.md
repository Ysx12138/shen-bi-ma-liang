# Support

Use the right GitHub channel so the repository stays useful:

| Need | Channel |
| --- | --- |
| Reproducible defect in a skill rule or validation | [Issue](https://github.com/Ysx12138/shen-bi-ma-liang/issues) |
| Workflow question, usage example, or design discussion | [Discussion](https://github.com/Ysx12138/shen-bi-ma-liang/discussions) |
| Security, credential, or unsafe-path concern | [Private vulnerability report](https://github.com/Ysx12138/shen-bi-ma-liang/security/advisories/new) |

When asking for help, include the Codex version if known, a minimal non-sensitive input description, the selected template, and the unexpected result. Never attach private source images, tokens, or local absolute paths unless they are essential and you are authorized to share them.
