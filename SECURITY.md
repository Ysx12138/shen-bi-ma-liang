# Security Policy

## Supported versions

Only the latest `main` branch is supported.

## Reporting a vulnerability

Do not post a suspected security issue, credential leak, or unsafe-path behavior in a public Issue. Use GitHub's private vulnerability reporting for this repository. Include the affected file, a minimal reproduction, expected and actual behavior, and whether any local files or credentials could be exposed.

This is an instruction-and-template project, not a hosted service. The most relevant reports are unsafe filesystem behavior, accidental publication of local paths or assets, prompt-injection paths, and repository secret exposure.

You should receive an acknowledgement after the report is reviewed. Please avoid public disclosure until the issue is understood and a fix or mitigation is available.
